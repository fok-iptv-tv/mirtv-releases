# IPTV — установка и обновления

**Скачать приложение:** откройте раздел [Releases](../../releases/latest) и скачайте файл `IPTV-*.apk` на Android-телефон или планшет, затем установите его (разрешите установку из этого источника).

Новые версии приложение находит само и предлагает обновиться.

Здесь же каждый день автоматически собирается каталог каналов (`catalog.json.gz`) из открытых источников: iptv-org, Free-TV, Pluto TV, Samsung TV Plus, Plex, Roku, LG Channels, Rakuten TV и FAST-списки Apsattv.
